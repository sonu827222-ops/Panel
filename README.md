# QuickSend

QuickSend ek simple tool hai jis se aap files ko jaldi aur asani se bhej sakte hain.

## Features

- Tez aur asaan file sharing
- Simple interface
- Kisi complicated setup ki zaroorat nahi

## Download

1. `QuickSend.zip` file download karein
2. Zip ko extract karein
3. App ko install ya run karein

## Istemal ka tareeqa

1. QuickSend open karein
2. Jo file bhejni hai usay select karein
3. Receiver ko choose karein aur Send dabayein

Kisi masle ya sawal ke liye GitHub par Issue open karein.
